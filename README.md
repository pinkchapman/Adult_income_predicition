# Описание проекта
В рамках проекта решалась задача классификации, а именно предсказание уровня дохода человека на основе социально-демографических характеристик.
Целевая переменная: income
Основные этапы работы были разделены на 4 отдельных тетрадки:
1 - eda
2 - baseline модели
3 - улучшение моделей и проверка гипотез
4 - подбор гиперпараметров
Для работы использовался датасет https://www.kaggle.com/datasets/wenruliu/adult-income-dataset/data
